## 📌 Overview
This project analyzes HR and payroll data to provide insights into salary distribution, employee structure, and department performance.

## 🎯 Objectives
- Analyze salary distribution across departments
- Evaluate overtime and allowance trends
- Compare job roles based on salary metrics
- Support HR decision-making

## 📊 Key Insights
- Marketing department has the highest total salary
- Overtime is significantly higher in Marketing and Procurement
- Administration has the lowest salary allocation
- Salary variation is noticeable across job roles

## 🛠 Tools Used
- Power BI
- Excel
